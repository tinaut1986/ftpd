- 3DSX: the in-app updater can now replace the running `.3dsx`.
- Release files no longer carry the version in their names (`ftpd-ex.nro`, `ftpd-ex.cia`, ...), so a manual download replaces the old copy.
- Settings: two-column layout with labels above the fields; Auto-update and the update channel share one row. The update switches were removed from Help.
- About: credits next to each version; "Check for updates" with its status alongside, What's New below.
- Help tabs are larger and clearer, open on the first touch (Switch) and switch with L / R.
- D-pad up / down scrolls the open dialog.
- Switch: X no longer presses the focused button instead of opening Help.
- Switch: holding - no longer makes the screen flicker on and off; + exits on press.
- Switch: warning in applet mode (launched from the album), which uses less memory for sockets.
- Updater retries DNS / connection failures and logs DNS diagnostics to `/config/ftpd/ftpd.log`.
